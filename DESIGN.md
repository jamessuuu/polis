# Polis — art direction

Written 2026-09-06 from a design-director pass, then AMENDED the same day after
the client rejected the first implementation outright ("1/1000"). The
amendments are marked. Where this document and `CHARACTERS.md` disagree, this
one wins on palette, lighting and type; that one wins on the character kit.

## 0. The finding that reorders everything

The city is authored at a scale it is never displayed at. One user unit is
~0.5 CSS px in the original 1180px column: a building is 32px, a citizen is
4.6px, face strokes are 0.3px. **No shading model rescues artwork drawn below
the resolution it is shown at.** Scale is item 1 and it is not negotiable.

## 1. Direction — AMENDED

**A living model city.** Warm, characterful, lit like a late-afternoon
diorama — the register of *Monument Valley*, *Two Point Hospital* and
*Townscaper*, not a museum survey model and not a neon data-city. It must read
as a **game world you look around**, with citizens visibly present and at
work, while every entity on it remains a real record.

The original direction ("The Survey Model": matte blocks on a white board,
no figures) was rejected by the client. It was tasteful and it was wrong for
the brief, which asked three times for characters and a game. Recorded here
so it is not re-proposed.

**The line between data and craft, stated once:** ENTITIES are data — every
building, citizen, banner, ruin and road is one record and nothing is invented.
ENVIRONMENT is craft — sky, ground material, light, shadow, haze and the board
the city stands on are the canvas, not claims about the ecosystem, and they
are allowed to be beautiful.

References and precisely what is taken:

| Reference | Taken |
|---|---|
| ustwo, *Monument Valley* | Depth from value steps, warm key + cool fill, flat faces with no texture, jewel-like restraint |
| Two Point Studios, *Two Point Hospital* | Characters as the life of the scene; readable at distance; rooms as coloured blocks with warm interiors |
| Oskar Stålberg, *Townscaper* | Contact darkening at every ground junction; variety generated by rule from a small kit |
| Eduard Imhof, cartographic relief | Aerial perspective as a contrast budget: subject full contrast, background recedes |
| Google Maps 3D vector layer | One restrained tint + one top/side split per building; labels on a separate plated layer |

Anti-references: stock "isometric city" vector packs (trees, cars, clouds);
neon cyberpunk grid-and-glow; Kurzgesagt gradient blobs; the beige-paper
civic-map look the first implementation shipped.

## 2. Palette

Authored in **OKLCH**. Each precinct is ONE token; every face, text colour and
swatch derives from it. `color-mix(in srgb, hue, #000)` is forbidden — it
collapses chroma faster than lightness and drags every hue to the same brown.

### 2.1 Derivation (identical for every precinct)

```css
.hue-03 { --hue: oklch(0.615 0.105 166); }         /* the only hand value */
.structure {
  --face-top:   oklch(from var(--hue) l               c             h);
  --face-right: oklch(from var(--hue) calc(l - 0.085) calc(c * 0.96) h);
  --face-left:  oklch(from var(--hue) calc(l - 0.170) calc(c * 0.88) h);
  --face-foot:  oklch(from var(--hue) calc(l - 0.265) calc(c * 0.78) h);
  --window:     oklch(0.93 0.09 85);                 /* warm lit glass */
}
```
Fallback (`@supports not`): `color-mix(in oklab, var(--hue) N%, var(--shadow-ink))`
at 86 / 71 / 58 %. Never toward `#000`.

### 2.2 Lightness ladder and division palette (Okabe-Ito hues retained)

Three tiers so hue-confusable neighbours are separated by value.

| # | Division | H | C light / dark | Tier | Roof L light / dark |
|---|---|---|---|---|---|
| 00 | Cabinet | 75 | 0.018 / 0.022 | T3 | 0.40 / 0.56 — graphite, the focal anchor |
| 01 | Intelligence | 248 | 0.115 / 0.105 | T2 | 0.505 / 0.67 |
| 02 | Product | 44 | 0.130 / 0.150 | T2 | 0.505 / 0.67 |
| 03 | Engineering | 166 | 0.105 / 0.100 | T1 | 0.615 / 0.78 |
| 04 | Design & Story | 352 | 0.105 / 0.115 | T3 | 0.40 / 0.56 |
| 05 | Growth & Revenue | 71 | 0.105 / 0.125 | T3 | 0.40 / 0.56 |
| 06 | Trust & Operations | 236 | 0.085 / 0.070 | T1 | 0.615 / 0.78 |
| 07 | Knowledge & Craft | 104 | 0.110 / 0.140 | T1 | 0.615 / 0.78 |

**Guilds** get a second, deliberately low-chroma family (C ≈ 0.045, L 0.56 /
0.64): agentic 290, automation 200, backend 145, design 352, game 30,
growth 90. Low chroma IS the class signal — unpainted brick beside painted
districts, which is their constitutional status. Skills in the Archive owned
by a guild take that guild's hue at the same chroma, so the Archive becomes a
library with six visible collections instead of an 86-box grey slab.

### 2.4 Contrast invariants (WCAG 1.4.11, non-text ≥ 3:1)

1. `ΔL(roof, plot-ground) ≥ 0.34` in OKLCH guarantees ≥ 3:1 in these ranges.
2. Dark theme: left wall and footing fall below 3:1 by design — the 1.1u
   `--rim` silhouette stroke is the compliant boundary and is not optional.
3. Colour is never the sole carrier: plate label, plan numeral, position,
   legend, `aria-label` and the panel all carry precinct identity.
4. `tools/contrast.mjs` must compute real OKLCH→sRGB→luminance and fail the
   build on any pair below threshold. Until it exists, every figure in this
   document is PREDICTED, not measured.

## 3. Lighting

One key light, screen upper-right, travelling down-left **exactly along +row**
so cast shadows are collinear with a box edge and reduce to 5 points.

| Surface | ΔL | ΔC |
|---|---|---|
| Roof | 0 | ×1.00 |
| Gable lit slope | +0.020 | ×1.00 |
| Gable shade slope | −0.055 | ×0.98 |
| Right wall | −0.085 | ×0.96 |
| Left wall | −0.170 | ×0.88 |
| Footing band (bottom 3.5u) | −0.265 | ×0.78 |

**No hue rotation anywhere.** The cool-shadow feel comes from `--shadow-ink`
on the ground, never from twisting a building's hue.

- **Cast shadow:** pentagon `[n, e, s+D, w+D, n+D]`, `D = (−1.10h, +0.55h)`.
  `--shadow-ink` at fill-opacity 0.13 light / 0.28 dark. One `.shadow-layer`
  after roads, before buildings. **Per-element fill-opacity, never group
  opacity** (a group opacity re-rasterises ~290 shapes on every zoom tick).
  Ruins cast no shadow — nothing stands there.
- **Contact patch:** one shared `radialGradient`, one ellipse per building.
- **Footing band:** bottom 3.5u of each wall as a separate quad.
- **Silhouette edge:** one outer path per citizen, 0.9u light / 1.1u dark.
  And **delete the background-colour face stroke** — the 0.3px pale grout
  between faces is half the sticker look. Faces self-stroke in their own fill.

## 4. Material and silhouette — derived from data only

| Feature | Driven by | Values |
|---|---|---|
| Roof form | `tools` includes Write/Edit (18/59) | gable (a workshop) vs flat parapet (a reading room) |
| Footprint | `model` | opus 0.78 · sonnet 0.72 · haiku 0.64 · unpinned 0.70 |
| Height | degree | 14 + 3.4/link, cap 82; +10 for Directors |
| Storey lines | degree (again, readable a second way) | one every 10.2u, two paths per building |
| Windows — AMENDED | degree | lit warm rectangles on the two walls, count = storeys; encode the same fact a third way and give the city its life at dusk |
| Banner | `director` | 20u pole, 12×7u swallowtail pennant in the precinct hue |
| Ruin | `unreachable` | dashed footprint only, `--warn`, NO volume, NO shadow, NO figure |
| Skill | kind | 11u monopitch shed, 0.62 footprint, no storeys, no edge — shelving |

**Gable geometry:** `RIDGE = clamp(0.16h, 5, 12)`; `R1 = mid(nT,wT) − (0,RIDGE)`,
`R2 = mid(eT,sT) − (0,RIDGE)`; lit slope `[nT,eT,R2,R1]`, shade slope
`[wT,sT,R2,R1]`, gable end `[eT,sT,R2]`.

**Plan numeral:** each district's number set INTO its ground with
`transform="matrix(1 0.5 -1 0.5 tx ty)"`, mono 700, size
`clamp(64, 0.40·min(cols,rows)·64, 220)`, fill `--numeral` at ~1.5:1 by design.
Districts only — guilds have no number and inventing one would be a lie.

## 5. Characters — AMENDED: RESTORED

The client asked for characters three times. They stay, and they are done
properly per `CHARACTERS.md`: a composable kit whose every feature maps to a
real attribute (tunic = precinct, insignia = division/guild, instrument =
tool axis Makes/Runs/Scouts, model chip = declared model with absence drawn
as absence). **Minimum 22u tall** — never again 9u. Two LODs: silhouette +
tunic + insignia below zoom 1.5×, full kit above. One figure per reachable
citizen, standing on the sidewalk in front of its building. Activity from
real telemetry (`data/workforce.json`): idle / recently active / active now /
crewed-with, per the visual language in `CHARACTERS.md` §5.

Element budget: ≤ 12 nodes per figure at full LOD.

## 6. Type

**No serif on the map.** `ui-serif` at 27u with a 6u paint-order halo was the
loudest amateur tell on the canvas.

```css
--font-display: "Segoe UI Variable Display", ui-sans-serif, -apple-system,
                "SF Pro Display", system-ui, "Segoe UI", Roboto, sans-serif;
--font-mono:    ui-monospace, "Cascadia Mono", Consolas, "SF Mono", Menlo, monospace;
```

| Role | Size (u) | Family | Weight | Tracking |
|---|---|---|---|---|
| Precinct number `03 ·` | 27 | mono | 700 | +0.02em, fill `--hue-text` |
| Precinct title | 27 | display | 620 | −0.005em |
| Precinct sub | 19 | mono | 400 | +0.02em, `--ink-muted` |
| Citizen name plate | 20 | mono | 500 | 0 |

**Every label sits on a plate.** `<rect rx=3>`, `--plate` @0.94, 1u border,
10u padding. **No `paint-order`, no `text-shadow`, anywhere.** Nothing
smaller than 19u exists on the map; if it has to be, the layout is wrong.

**Name plates are mandatory.** The page copy promises "Directors are always
named; everyone else's name appears on hover" and the first implementation
drew no name text at all. A pool of 16 plate groups created at load,
repositioned by transform on hover/focus/select; the seven Director plates
always mounted. Hover creates zero DOM nodes.

## 7. Composition and camera

- Map container `width: min(100vw − 2rem, 1480px)`, centred by transform
  (not by vw margins, which resolve against the parent and clipped the toolbar).
- `TOP_ROOM 300 → 96`, `PAD 90 → 64`. ViewBox ≈ 2176 × 1184.
- **The board:** the city stands on a plinth — the ground diamond plus two
  14u extruded edge faces plus a 1.5u outline. An object on the page, not a
  drawing floating on it.
- **Sky:** a vertical gradient `--sky-top → --sky-bottom` behind the board.
  Environment, not data.
- **Streets for free:** plot ground LIGHTER than street in light theme,
  darker in dark — the 1-tile gaps between plots read as pavement with zero
  new nodes. One tile-grid `<path>` per plot, 0.5u @0.35, 17 paths total.
- **The wall:** two back faces lit properly, plus the two FRONT edges as a
  4u kerb — a wall that stops halfway reads as an accident.
- **Archive behind the city:** bearing `−3π/4`, placed FIRST among outside
  precincts so the six guild halls cannot box it out. Hazed, receding, a
  backdrop of 86 sheds instead of an obstruction in the foreground.
- **Aerial perspective:** two gradient planes. Ground haze below buildings at
  0.40α; object haze above buildings capped at **0.10α** — the cap is
  arithmetic: veiling a T1 roof past 0.102α drops the back rows below 3:1.

Focal order: graphite Cabinet with chief-of-staff's tower → ring of
saturated districts → wall → low-chroma guild halls and Archive → plinth edge.

## 8. Motion

Only `opacity` and `transform` ever transition. **Never `stroke-width`** —
this repo's own scar, and the first implementation broke it again in three
`:hover`/`:focus-visible` rules. Silhouette highlight is a pre-rendered edge
path revealed by opacity; roads are pre-rendered twice (rest + highlight).

| Element | Property | Timing |
|---|---|---|
| structure dim | opacity → 0.22 | 140ms cubic-bezier(.2,0,0,1) |
| structure active / neighbour | translateY(−5u / −2u) | 140ms |
| name plates | opacity 0→1, translateY(3u→0) | 120ms |
| figure idle — AMENDED: kept | translateY ±1.8u, staggered per figure | 3.4s ease-in-out |
| figure working | a tool-swing on the instrument, transform only | 1.2s |

`prefers-reduced-motion: reduce` removes every transition and the idle bob;
no state is reachable only through motion. Camera pan 1:1, no inertia.

Budget: **≤ 2,400 SVG elements** (figures restored). **No `<filter>`, no
`feDropShadow`, no CSS `filter:` on any map element.** Group opacity only on
the two haze planes.

## 10. Rejected alternatives

| Rejected | Why |
|---|---|
| The Survey Model (matte blocks, no figures) — the first direction | Rejected by the client. Contradicted a brief that asked for characters and a game three times. |
| Neon data-city | The distributional default for "agent visualisation"; reads as generated; needs a filter budget the constraints forbid. |
| Gradient-filled faces | `var(--hue)` cannot resolve inside a `<defs>` gradient (it inherits from the SVG root), so it needs 2 defs per hue. Muddies the material for more nodes than the footing band. |
| Per-element opacity for depth | 145 offscreen composites on every zoom tick. Two haze planes, two nodes. |
| Group opacity on the shadow layer | Same jank class. Per-element fill-opacity and the occasional 0.24 pocket. |
| Masts for WebFetch (38/59), chimneys for Bash (37/59) | A two-thirds majority as an ornament is a forest, not a signal. Marks are for scarce traits. |
| Windows as pure ornament | Kept ONLY because count = storeys = degree; a window that encodes nothing is the prettier lie. |
| Skewing labels into the ground plane | Beautiful once, unreadable at 27u. Only the numeral earns the skew. |
| The beige-paper civic map | Shipped by accident as the mid-state. The serif fights the geometry; halos are a workaround for missing plates. |
